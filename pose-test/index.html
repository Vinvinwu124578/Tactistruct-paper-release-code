Protocol and limitations

Within each protocol, the saved input points were rotated about the normalized object origin around +X. The model received those rotated points directly, without pose correction or rescaling. The prediction was rotated back only for scoring.

The 4- and 40-patch inputs are balanced samples of 1,024 points. The raw ten-patch input retains all 30,000 points. The 40-patch cloud uses one color because the archive does not contain per-point patch IDs.

The 0° row reuses the upright results. CD is the sum of mean nearest-surface distances in normalized coordinates. The full mean includes the out-of-bounds reference; the valid-reference mean excludes only that case. No S0, reference CAD or model weights are included.
