Protocol and limitations

All objects use the same B checkpoint (epoch 850, seed 42), selected by development CD. The input view shows all 1,024 points actually fed to the model, balanced over 40 patches drawn from four saved simulation groups. The prediction is the mesh extracted from a fixed 96³ field. Input and prediction share the same orthographic view and scale within each case; the scale may differ between objects.

CD is the sum of the two mean nearest-surface distances, not squared, in normalized coordinates. F-scores use thresholds 0.01 and 0.02. Each surface evaluation sampled 10,000 points.

Training figures are in-sample; validation is reused development data. The test tab contains the original test partition, not S0. Cases sharing shape IDs across historical splits are flagged. One invalid test reference is retained in the archive and contributes to the raw summary. The gallery contains images and metrics, plus the sampled model-input XYZ, not source CAD, complete touch archives, or weights.
